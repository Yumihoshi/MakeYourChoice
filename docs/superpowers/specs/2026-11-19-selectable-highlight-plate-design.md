# 暂停面板滑条整条高亮修复（2026-11-19）

## 背景

暂停面板的音量与音效滑条由 `SelectableHighlight` 提供焦点反馈。该组件把序列化的 `plate` 当作「底色」，指针悬停或手柄选中时从 `plateNormal` 渐变到 `plateFocus`。这两根滑条的 `plate` 指向了整条轨道背景，于是指针停在滑条上时整根轨道都变成焦点色：音量调到 0% 时填充宽度为 0，画面却是一整条琥珀色，看起来像满格。

## 设计决定

- 新增布尔字段 `tintPlate`（默认 `true`，保持按钮原有表现）。关闭后 `SelectableHighlight` 不再要求或写入 `plate`，只改描边、文字、强调图形（滑条把手）与缩放；`Awake` 里缺 `plate` 的报错也只在 `tintPlate` 为 `true` 时触发。
- 暂停面板的两根滑条设 `tintPlate = false` 且 `plate = null`；按钮保持 `true`。滑条的当前值只由 Fill 的宽度表达，焦点反馈落在把手与标签上，未填充部分始终是深色轨道。
- 不改 `Slider` 自身结构（Fill / Handle 引用、方向、轨道颜色都保持原样），也不为滑条单独写组件。

## 验收

- Play → Esc 打开暂停面板 → 鼠标悬浮音量滑条并拖到 0%，轨道整条保持深色，只有把手与文字变成焦点色。
- 音效滑条同理；按钮（继续游戏 / 退出）的整块底色仍会随焦点与悬停变化。
- 手柄 / 键盘导航选中滑条时表现一致；面板反复开关、进出 Play 不应残留高亮。
