泳池房流程逻辑规格

MakeYourChoice · Unity 2022.3.62f3c1 / URP 14 · 规格日期 2026-11-21 · 基线 docs/superpowers/specs/2026-11-21-pool-room-design.html · 场景 Assets/Scenes/Level1.unity / Assets/Scenes/Level2.unity · 状态：设计已确认，待实现

一句话：不改泳池房几何，用场景实例上的 PoolFlowState 串起 8 步——更衣室 00 暗门 → 轮与长池退水 → 池底钥匙 → 37 号柜扳手 → 主阀与池核退水 → 地漏下坠。所有交互复用 InteractableBase、CabinetDoorInteract、DialogueTrigger，不新增事件总线、不做存档、不做背包 UI。

0. 范围与前置

本规格包含

  • 8 步流程的状态机与门控
  • 00 暗门、37 号柜的锁与解锁
  • 轮拾取、安装、按住旋转 3 圈
  • 长池 / 池核两次退水与空气墙关闭
  • 池底数字、00 号牌、长池新台阶
  • 地漏洞、竖井、下一关接口
  • Yarn 节点、触发区与文字锚点
  • Level1 实例与 Level2 调试场景各一套接线

本规格不包含

  • 下一关的场景内容、淡出、加载流程
  • 存档 / 读档；离开场景重进即重置
  • 背包、道具栏、HUD 文字
  • 水面材质、水花、音效的新增
  • 更衣室 01..54 号储物柜的独立交互

已确认的修正：道具/主阀 保留现有 PumpLP_part1，它就是主阀，不再替换成 Valve.prefab；新导入的抽水泵在 Assets/Art/Models/抽水泵/，单独处理后放到泵房基座；删除没有子物体的空轮；储物柜_54 去重复组件；储物柜_37 按本规格加门与柜内扳手；所有拾取物/主阀/阀接口的碰撞盒由实现时统一补。

2. 状态机

2.1 PoolFlowState 字段

普通 MonoBehaviour，挂在两个场景的泳池房实例旁（Level1 在 口袋空间/TestRoom 下，Level2 在 泳池房 下）。字段全部 public bool X { get; private set; }，只由对应的 MarkX() / TakeX() 改写；不继承、不静态、不发事件。

2.2 门控表

可交互物CanInteract() 条件点击结果
00 暗门（双门）!PoolNumberSeen 时 SilentLocked，直接 false无准心、无反应；看到 00 后解锁并自动打开
37 号柜前门FeedbackLocked 时仍 true（可瞄准）没钥匙：播“锁着”；有钥匙：正常开关

钥匙LongPoolDrained && !HasKey置 HasKey，隐藏钥匙，解锁 37
扳手HasKey && !HasWrench置 HasWrench，隐藏扳手
主阀!CoreDrained && !_busy没扳手：首次播提示；有扳手：启动并退水

为什么轮要等 WrenchNeedLearned：玩家可能在泵房先看到轮。若允许直接捡，玩家会绕过“主阀要扳手”的认知，第 4 步就失去意义。门控后，玩家必须先听主阀提示（或穿过暗门），轮才出现准心。

3. 交互设计

3.1 输入

沿用 PlayerInputRouter.Interact：鼠标左键 <Mouse>/leftButton 与手柄 <Gamepad>/buttonSouth。不新增按键、不做长按提示 UI；准心与按键图标继续由 InteractFocus / InteractPromptView 负责。

3.2 给 InteractableBase 加“按住”钩子

现在基类的 Update() 只在 WasPressedThisFrame() 时调 OnInteract()，子类无法接管按住。做最小扩展，不改变现有子类行为：

protected virtual bool IsHoldInteraction => false;
protected virtual void OnInteractHeld(float deltaTime) { }

void Update()
{
    if (!IsAimed()) { InteractFocus.Clear(this); return; }
    InteractFocus.Set(this);

    var input = PlayerInputRouter.Instance;
    if (input == null) return;

    if (IsHoldInteraction)
    {
        if (input.Interact.IsPressed()) OnInteractHeld(Time.deltaTime);
    }
    else if (input.Interact.WasPressedThisFrame())
    {
        OnInteract();
    }
}

只有长池阀重写 IsHoldInteraction；其他交互物保持“按一下”。按住期间视线离开、光标解锁、剧情锁控制都会让 IsAimed() 返回 false，自动停转，不需要额外状态。

3.3 拾取：轮 / 钥匙 / 扳手

三者共用一个 PoolPickupInteract : InteractableBase，用枚举区分，不写三个脚本。

枚举可交互条件拾取后
WheelWrenchNeedLearned && !HasWheel && !WheelInstalledTakeWheel()，隐藏轮，播 LV2_Pool_WheelPicked
KeyLongPoolDrained && !HasKeyTakeKey()，隐藏钥匙，对 37 前门 Unlock()，播 LV2_Pool_Key
WrenchHasKey && !HasWrenchTakeWrench()，隐藏扳手，播 LV2_Pool_Wrench

拾取后 gameObject.SetActive(false) 即可：碰撞体、渲染、准心一起消失；不做“飞到手上”的动画，也不做背包。

飘字锚点不能挂在拾取物上：拾取物会立刻 SetActive(false)，如果 DialogueTrigger.textAnchor 指向它，3D 飘字会失去锚点。每个拾取物原位另放一个不会被隐藏的空锚点（剧情锚点/交互点_轮、交互点_钥匙、交互点_扳手），DialogueTrigger 统一挂在 泳池房/流程/剧情 下的常驻对象上，拾取物只持有它的引用。

3.4 长池阀：安装 + 按住转 3 圈

在 管道_轮阀接口/锚点_轮阀安装位 下建空物体 阀_长池，挂 PoolValveWheelInteract 与一个覆盖法兰的 BoxCollider；其下预放 inactive 的 Valve.prefab 子物体 轮_已安装，local 位置/旋转归零、scale 0.486，与拾取轮一致。

阶段条件行为
安装HasWheel && !WheelInstalled左键：MarkWheelInstalled()，隐藏拾取轮，激活 轮_已安装，播 LV2_Pool_InstallWheel
旋转WheelInstalled && !LongPoolDrained按住左键：绕阀轴以 240°/s 旋转，累计 1080°（3 圈，约 4.5 s）
完成累计 ≥ 1080°调 PoolWaterDrain.DrainLongPool()，本交互不再响应
实现注意：CanInteract() 必须同时覆盖“未安装”和“已安装”两个阶段，例如 !LongPoolDrained && (HasWheel || WheelInstalled)；否则装上轮后 CanInteract 变 false，IsAimed 直接拦住，按住永远不生效。旋转用 wheel.Rotate(axis, degrees, Space.World)，轴取锚点的 forward（+X），不要用模型自身欧拉角硬凑。

3.5 主阀：一次点击启动

PoolMainValveInteract 挂在 道具/主阀 上，组件与 PumpLP_part1 同根；给主阀根加 BoxCollider（实际采用 1.6 × 1.6 × 1.6）覆盖模型。主阀不需要扳手模型，也不需要按住。

  1. 没扳手：只播 LV2_Pool_NoWrench；不置位 WrenchNeedLearned，避免玩家绕过暗门直接解锁轮。
  2. 有扳手：播 LV2_Pool_MainValveOpen，PumpLP_part1 绕 道具/主阀/旋转轴 的 forward 转 360°、1.2 s；结束后 MarkMainValveOpened()，调 DrainCorePool()。模型本地轴不是轮面法线时，在 道具/主阀 下加空物体 旋转轴 并让组件绕它的 forward 转，不要硬改模型欧拉角。
  3. 已退水：CoreDrained 后不再响应。

3.6 柜门锁：Silent 与 Feedback

CabinetDoorInteract 增加锁模式与两个公开方法，不新建子类：

public enum LockMode { Unlocked, SilentLocked, FeedbackLocked }

[SerializeField, LabelText("初始锁状态")]
LockMode lockMode = LockMode.Unlocked;

[SerializeField, ShowIf(nameof(lockMode), LockMode.FeedbackLocked), LabelText("上锁提示剧情")]
DialogueTrigger lockedDialogue;

public void Unlock() => _locked = false;
public void Open() { /* 未锁、未动、未开时 SetOpenAsync(true).Forget() */ }
模式CanInteract()点击用在哪
Unlockedtrue正常开关普通柜门
SilentLockedfalse（无准心）无反应00 暗门，满足第 1 步“不能与储物柜交互”
FeedbackLockedtrue（有准心）播 lockedDialogue，门不动37 号柜，空手点给“锁着”

FeedbackLocked 必须配 lockedDialogue；缺失时 Awake 里 Debug.LogError 并禁用，不静默。

6.2 触发规则

  • 泵平台：PoolStoryTrigger(Beat.PumpHint) + BoxCollider（实际 2.2 × 1.5 × 2.2，中心 (-15.8,0.9,27.0)）；进入一次置 PumpHintHeard 并播。
  • 暗门内侧：PoolStoryTrigger(Beat.NeedWrench) + BoxCollider（实际 1.5 × 2 × 1，中心 (-20.5,1.0,20.15)）；从暗门进泵房时置 WrenchNeedLearned。若玩家走长廊绕进泵房，空手点主阀只播 LV2_Pool_NoWrench，不会置位；仍必须穿过暗门触发“要扳手”才能捡轮。
  • 池底数字：PoolNumberSightTrigger 挂在 流程/池底数字判定；观察区 BoxCollider 覆盖泳池区（实际 10 × 3 × 14，中心 (-18.5,1.5,36.0)）；eye/viewCamera 为空时取 Camera.main，取不到就 LogError 并禁用。
  • 拾取物 / 主阀 / 阀接口 / 竖井：各自 InteractableBase 或触发器，不再经过 TriggerVolume。拾取物的 DialogueTrigger 不要挂在会被隐藏的对象上，见 3.3。
不要用 ScreenVisibility 判池底数字：它内部是 Physics.Linecast，而池边的空气墙有 Collider，会挡在相机与池底之间，导致永远判不可见。数字判定改成“相机视口内 + 水平角 ≤ 20° + 距离 ≤ 15 m + 玩家在观察区内”，不引 Physics.Linecast。

// PoolValveWheelInteract：两个阶段都要让 CanInteract 为真
protected override bool CanInteract()
    => !state.LongPoolDrained && !_draining
       && (state.HasWheel || state.WheelInstalled);

protected override bool IsHoldInteraction
    => state.WheelInstalled && !state.LongPoolDrained && !_draining;

// PoolWaterDrain：本地 y 下降，2 s，结束禁用
for (var t = 0f; t < duration; t += Time.deltaTime)
{
    var k = Mathf.Clamp01(t / duration);
    foreach (var s in surfaces) { var p = s.localPosition; p.y = Mathf.Lerp(startY, lowerY, k); s.localPosition = p; }
    await UniTask.Yield(PlayerLoopTiming.Update, destroyCancellationToken);
}
foreach (var s in surfaces) s.gameObject.SetActive(false);
foreach (var b in blockers) b.gameObject.SetActive(false);

异步统一 async UniTaskVoid + .Forget()，最外层 catch (OperationCanceledException) 静默退出；等待用 destroyCancellationToken，不写协程。

9. 验收

9.1 正向

  1. 进入更衣室，对准 01..54 任意柜：无准心、按键无反应；00 暗门也无准心。
  2. 走正门到泳池房；站上/靠近抽水泵基座：播 LV2_Pool_PumpHint，只播一次。
  3. 在泳池区把视线落到长池南叶池底：看到亮黄色 00，播 LV2_Pool_Number；回更衣室，00 暗门前后双门已打开。
  4. 穿过暗门进泵房：播 LV2_Pool_NeedWrench；泵房地上的轮出现准心。
  5. 捡轮 → 到长池阀接口左键安装 → 按住左键约 4.5 s，轮转 3 圈 → 长池 3 块水面 2 s 内降到 -1.55 并消失，4 块空气墙关闭，播 LV2_Pool_LongDrained。
  6. 从南岸走新台阶下到长池池底，捡钥匙；钥匙消失，37 号柜前门解锁。
  7. 回更衣室开 37 柜，拿扳手；到泵房点主阀，主阀轮转 1.2 s，池核 4 块水面降完消失，5 块空气墙关闭，播 LV2_Pool_CoreDrained。
  8. 从干区平台坠入池核，走到地漏，从 0.9 × 0.9 洞落进竖井；底部触发一次 NextLevelReached 与 onNextLevel。

9.2 反向

  • 没看 00 前，00 暗门无准心；37 柜有准心但只播“锁着”，门不开。
  • 没钥匙点 37：门不动，不消耗任何东西。
  • 没扳手点主阀：只播短句，池核不退水；重复空手点不重复播。
  • 没装轮时长池阀无准心；装上轮但没转满 3 圈，长池不退水。
  • 退水途中再点阀/主阀：无响应；退水完成后再次进入触发区：不重播。
  • 池核退水前，玩家从干区平台走向池核会被空气墙挡住；退水后可坠入。
  • 竖井底触发只发一次；事件留空时玩家落在底板上。
